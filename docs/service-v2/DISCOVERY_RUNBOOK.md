# 04 장소 탐색 실행 계약

이 단계는 기존 단일 FastAPI·SQLite·작업 dispatcher를 재사용한다. 예약·질문·메일·리뷰 근거·설정 진입 경로를 유지하고 **탐색**을 추가한다. 일정 편집·예약 실행·외부 결제는 05단계 이후의 별도 기능이다.

## 구현과 검증 순서

1. 여행 조건 → 비공개 장소 보관함 → 지점 선택 → 필드별 사실·출처. 이 묶음의 저장·API·화면·오류 처리를 먼저 검증한다.
2. 저장 조건 snapshot → 후보·자격·필수 조건 → 세 가지 점수 모델 → 다양성 → 서버 설명. 결과와 작업 ID를 저장하고 다시 읽는다.
3. 이전 결과를 유지하는 명시적 조건 적용, 상세, 같은 방문일·인원으로 최대 세 장소 비교를 연결한다.

실제 명령·최종 결과는 `IMPLEMENTATION_STATUS.md`와 `reports/discovery-validation-2026-10-05.md`에 기록한다. 이 문서의 절차 자체는 실행 증거가 아니다.

## 개인정보와 외부 호출

모든 탐색 API는 기존 세션·Origin·CSRF 검사를 사용한다. 개인 저장과 공용 근거를 다른 테이블에 둔다. 다른 사용자의 여행·보관함·결과 ID는 404다. 브라우저 앱 셸 이외의 개인 응답은 캐시하지 않는다.

장소 이름·URL을 저장하는 것과 지점의 정체를 확인하는 것을 분리한다. 첫 resolver는 검수한 서버 후보 목록을 대조한다. 정확한 지점 후보가 여러 개면 선택을 요구하고, 알 수 없는 URL이나 단축 URL은 보존하되 자동으로 유명 지점에 연결하지 않는다. 추천 실행으로 리뷰를 재수집하지 않는다.

`src/discovery/safe_fetch.py`는 외부 수집을 추가할 때 사용할 제한된 reader다. 현재 외부 URL 원문을 무조건 가져오는 API를 열기 위한 우회 경로가 아니다. 사용 전 해당 출처의 접근·처리·저장·표시 범위를 확인하고, 유료 호출이면 기존 비용 gateway를 반드시 적용한다. reader는 HTTP(S) 표준 포트·공개 DNS 전체·실제 연결 IP·매 redirect를 검사한다. DNS 확인 뒤 숫자 IP로 socket을 고정하고 TLS 인증서는 원래 hostname으로 검증한다. 응답 MIME·바이트·시간·redirect를 제한하며 HTML·스크립트·하위 리소스를 실행하지 않는다.

## 합성과 실제 자료의 구분

`tests/discovery_synthetic.py`의 장소·주소·가격·출처는 오직 합성 검증용이다. 운영 코드가 이를 자동 seed하지 않는다. 브라우저 fixture는 별도 임시 SQLite·합성 OIDC·가짜 제공자만 사용한다.

실제 후보는 `examples/real-discovery-candidates.json`과 `reports/DISCOVERY_CANDIDATE_AUDIT.md`에 남긴 출처를 검수한 후 관리자 권한으로 가져온다. 공개 페이지를 읽었다는 사실은 모든 가공·보관·표시 권한이나 예약 가능성을 증명하지 않는다. 검수 전 후보는 준비 중이며, 확인하지 못한 도시를 합성 장소로 채우지 않는다.

현지어 웹사이트는 지역 이용자의 비율 근거가 아니다. 리뷰 근거는 03단계의 운영·정책·품질 gate를 그대로 따른다. OFF/만료/자료 부족은 unavailable이며 한국어 0%로 대체하지 않는다.

## 사실 해석

- 통상 시간표, 특별 휴무, 브레이크, 마지막 주문, 입장 마감을 각각 유지한다. 미래 방문일의 영업 확정에는 해당 날짜 적용 근거가 필요하다.
- 시설 총좌석, 한 번의 예약 최소·최대 인원, 아동 규칙, 특정 날짜·시각·인원의 실제 잔여석을 합치지 않는다. 외부 링크 클릭은 예약 완료가 아니다.
- 가격은 통화·범위·인당/그룹·식사/하루/방문·세금·보증금을 보존한다. JPY와 EUR 단위를 무단 변환하지 않는다.
- 출처의 발행·확인·유효·만료 날짜가 다르다. 새 출처 하나로 관계없는 모든 사실의 확인일을 갱신하지 않는다. 상충 값은 함께 표시한다.

| 저장·권한 | A/B×두 여행, owner_id 거절, 같은 이름 다른 지점, 중복 URL·개인 메모 보존, 세션 만료 |
| 출처·보안 | 출처 미열람·권한 철회·만료·상충, 내부망·redirect·DNS 변경·MIME·크기·timeout |
| 추천 | 도쿄 4인/바르셀로나 2인, 유형과 분류 독립, 휴무·인원 불일치 우선, 미확인 별도 |
| 점수 | 세 모델 고정 가중치, 결측 total=null, 동일 입력 재현, 같은 chain의 다른 지점 |
| 리뷰 | 엄격 통과 두 곳만 반환, 번역만 존재·한국어 0/unknown 과다·운영 OFF·만료 |
| 설명 | 새 장소·순서 변경·출처 없는 예약 숫자·주민 비율 거절 후 템플릿 복구 |

| 화면 | 저장→추천→상세→비교, 최대 세 곳·동일 조건, 320px·긴 이름·큰 글자·키보드·포커스 |
