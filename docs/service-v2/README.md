# Travel Agent 제품 기획과 구현 문서

2026년 10월 1일 개정했습니다. 현재 Travel Inbox RAG의 예약 정리·근거 답변을 유지하며, **여행 조건에 맞는 현지 탐색과 대표 명소를 찾고 방문 준비와 일정 변경까지 돕는 제품**으로 확장하는 설계입니다.

대상은 사용자가 확인한 본인·소수 지인용 비공개 베타입니다. 비용을 낮추고 일본과 바르셀로나부터 사용하고 싶다는 요구를 반영했습니다. 초기 추천 지역은 도쿄·바르셀로나이며, 그 밖의 지역 예약도 그대로 보존합니다. 이 문서 묶음은 구현 명세와 프롬프트이며 아직 해당 기능이 운영 중이라는 뜻은 아닙니다.

## 이번 개정의 핵심

**Places API의 최대 5개 제한은 Google 지도 웹 리뷰를 더 수집할 수 없다는 뜻이 아닙니다.** Apify·Outscraper·SerpApi는 더 많은 리뷰를 수집하는 경로를 문서화하고 있습니다. 따라서 크롤링 검증을 핵심 개발 트랙에 넣었습니다. 다만 현재 동작·전수 수집·이용 권한까지 문서만으로 검증한 것은 아닙니다. [수집 방법과 비용 조사](CRAWLING_FEASIBILITY.md)

최근 수집 범위의 언어 분포인 observed_window를 먼저 만듭니다. 장소 전체 리뷰 비율을 추정하는 population_estimate와 구분합니다. 최신순으로 확보한 200건의 언어 비중은 관측 범위의 특징으로 활용할 수 있지만, 이를 전체 리뷰나 현지 주민의 비율로 표시하지 않습니다.

기능은 이름만 나열하지 않고 사용자 행동·화면 상태·데이터·오류·복구·인수시험까지 연결했습니다. 리뷰 원문 추출 실패, 한국어를 다른 언어로 잘못 판별하는 문제, 일정 수정 충돌, 재시작 중 삭제 데이터 부활, 중복 과금까지 설계에 포함했습니다.

## 제품 방향

| 영역 | 결정 또는 제안 |
| --- | --- |
| 핵심 흐름 | 여행 입력 → 장소 보관함 → 현지 탐색·대표 명소 → 상세·비교 → 일정 → 예약 준비·당일 변경 |
| 추천 유형 | 현지 탐색 / 대표 명소 |
| 장소 종류 | 음식점 / 카페 / 볼거리. 추천 유형과 별도 필터 |
| 현지 탐색 근거 | 검증한 최근 리뷰 언어 + 독립 지역 자료 + 취향·동선·방문 조건 |
| 리뷰 기본 단위 | 수집 범위·원문·미판별·기간이 명시된 관측 집계 |
| 예약 정보 | 방법·오픈 규칙·인원 제한·시설 정원·실시간 자리 구분 |
| 초기 기술 | 기존 FastAPI·PWA, SQLite, 여행별 Chroma, DB 작업과 예산 |
| 상시 운영 | Render 유료 compute와 영구 디스크 우선, Sites 화면은 후속 선택 |
| 운영 원칙 | 개인 예약 격리, 공급자 장애 중 읽기 유지, 미확인 표시, 재시작·삭제·복원 검증 |

## 권장 시작 범위

첫 베타에는 로그인·여행·예약 격리, 장소 URL 보관함, 두 추천 구획, 상세·후보 비교, 일정 생성·편집을 우선합니다. 리뷰 언어 기능은 개발 초기에 수집·권한·품질을 검증하고 통과하면 첫 베타에 연결합니다. 데이터가 부족하면 부족한 이유를 명시하고 임의의 통계를 만들지 않습니다.

그다음 예약 준비 목록·현지어 문의 초안, 상황별 대체 일정과 오프라인 오늘 보기를 추가합니다. 동행자 투표, 메뉴 OCR, 실시간 혼잡·잔여석, 자동 예약·결제는 후속으로 나눕니다.

첫 구현 요청은 [01단계 프롬프트](prompts/01-foundation.md)를 사용합니다. [단계별 실행 안내](PROMPT_PLAYBOOK.md)의 순서로 진행하고, 기존 P00~P13은 세부 작업을 나눌 때 참고합니다. 리뷰 공급자 조사는 기반 안정화와 병행할 수 있고 집계는 합성 데이터로 먼저 완성할 수 있습니다. 06단계에서 R1 핵심 베타를 준비하고, 07~08단계에서 실사용 보강과 피드백을 다룹니다.

## 비용의 의미

정확한 월 예산은 아직 사용자가 확정하지 않았습니다. 제안은 최소 서버·디스크 약 $7.25부터, AI·검색 월 $5 내부 한도, 리뷰 실험 A·B 합산 $3의 별도 한도입니다. 메모리 증설·백업·세금·환율·추가 트래픽은 별도입니다. [고정비 검토](DATA_AND_OPERATIONS.md)

Apify Free 단가에서 30곳×200개는 리뷰 이벤트 사용액 약 $3.60이지만 무료 크레딧·부가 비용·최소 구독 여부에 따라 실제 결제가 다릅니다. 같은 달 실험 A·B와 운영 후보팩을 모두 수집하면 리뷰 이벤트만 $5.16이므로 $5 크레딧으로 전 과정을 끝낸다고 가정하지 않습니다. 상세 계산과 공식 출처는 [크롤링 비용표](CRAWLING_FEASIBILITY.md)에 있습니다.

## 검증 범위

이 개정에서 실제 크롤러, 계정, 유료 리소스, 운영 배포를 실행하지 않았습니다. 공급자 문서와 공개 가격 정보를 확인했고, 문서 간 계약·합성 예시·링크·JSON을 검토했습니다. 기존 코드 테스트 117개 통과는 앞선 코드 감사의 기준이며 이번에 추가한 64개 시험을 실행했다는 뜻이 아닙니다.
