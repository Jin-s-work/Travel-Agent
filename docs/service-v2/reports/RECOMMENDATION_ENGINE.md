# 추천 계산 v1 검증 범위

구현: `src/recommendations/engine.py`, `explanations.py`.
순수 함수 `recommend(snapshot, candidates, now, config)`는 호출자가 고정한 시각과 저장된 조건·후보로 계산한다. DB, 검색 공급자, LLM을 호출하지 않는다. 서비스는 원본 조건과 후보 manifest를 저장하고 근거 변경 시 이전 결과 사용을 중단한다.

## 가중치와 결측

| 모델 | 성분 가중치 |
| --- | --- |
| `local_editorial_v1` | 지역 근거 .35 / 취향 .25 / 동선 .20 / 방문 조건 .10 / 가격 .10 |
| `iconic_v1` | 대표성 .30 / 취향 .25 / 동선 .20 / 방문 조건 .15 / 가격 .10 |
| `local_observed_v1` | 언어 .25 / 지역 근거 .20 / 취향 .20 / 동선 .15 / 동일 플랫폼 품질 .10 / 방문 조건 .10 |

이 가중치와 아래 매핑은 검증할 제품 가설이다. 방문 성과·주민 선호를 학습하거나 측정한 점수가 아니다. 성분은 0~1이고 근거가 없으면 null이다. 하나라도 null이면 총점도 null이며 남은 가중치를 재분배하지 않는다. 필수 조건 미확인은 `needs_confirmation`, 방문 조건은 확인됐지만 점수 자료가 부족하면 `insufficient_data`, 명시적 불일치는 `excluded`다. 해당 목록을 적합 후보의 순위에 합치지 않는다.

- 지역 근거: 읽기·사용 정책이 허용된 독립 지역 편집 출처군 1개 .5, 2개 이상 1.0. 직접 확인 근거 1.0. 운영자 자기소개나 관광 홍보만 있으면 독립 지역 성분을 채우지 않는다. 합성 출처는 합성 후보의 시험에만 사용한다. 같은 출처군의 재전재는 한 개다.
- 대표성: 검토된 도시 대표성 .6, 국가 대표성 .8, 세계 대표성/유산 근거 .9, 직접 확인 1.0. 이는 문화적 가치의 실측치가 아니다.
- 취향: 사용자가 명시한 고유 태그 중 후보 태그와 일치하는 비율. 태그 선호가 없으면 null이며 보통 선호를 임의 생성하지 않는다.
- 동선: 검토 후보의 좌표와 출발점이 있을 때 Haversine 직선거리로 `max(0, 1-distance_m/5000)` 계산. 거리 척도 5km는 설정 가설이다. 도로·교통 경로나 도보 소요 시간이 아니며 `estimate`로 표시한다. 반경 조건도 직선 반경이다. 검증된 이동 경로 공급자는 아직 연결하지 않았다.
- 방문 조건: 실제 검사한 필수 조건 중 확인된 비율. unknown을 충족으로 세지 않는다. 이 수치와 별개로 필수 조건 중 unknown이 있으면 적합 목록에 진입하지 못한다.
- 가격: 입력 예산과 검증된 가격 범위가 같은 통화·기준 기간·인당/전체 기준으로 일치하면 1.0. 범위 밖이면 0 및 제외. 경계가 겹치거나 단위·아동 가격을 모르면 null. 성인만 있는 인당↔전체 전환은 인원수로 정확히 계산하며 환율·아동 할인은 추정하지 않는다. 값이 없으면 0원으로 채우지 않는다.
- 관측 언어: 03단계 gate를 통과한 관측 창의 현지어 비율 하한. 거주민 비율·전체 리뷰 모집단 비율이 아니다. 엄격 요청 시 자료가 부적격해도 편집 모델로 전환하지 않는다.
- 플랫폼 품질: 허용된 동일 플랫폼의 5점 평점/5. 전체 평가 수와 평점 임계값을 별도 검사하고 비교 집단 식별자가 없으면 null. 베이지안 보정·도시별 수치 표준화는 아직 검증하지 않아 사용하지 않는다. 전체 평가 수를 리뷰 언어 분모로 사용하지 않는다.

초기 다양성 상한은 동일 체인 2개, 동일 동네 3개, 같은 분류 4개이고 각각 설정 가능하다. 순위는 총점 내림차순, 동점은 안정적인 내부 장소 ID 순이다. 상한을 채우려고 엄격 조건을 완화하거나 부적합 장소를 끼워 넣지 않는다. 같은 내부 장소 ID에 상충 payload가 오면 지점 자료 확인이 필요한 상태로 제외한다.

## 시간·인원·출처 계약

일반 미래 주간 시간표는 방문일 확정 시간표가 아니다. 방문일 또는 유효기간이 확인된 시간표, 날짜별 예외, 다음 날 종료, 별도 브레이크·마지막 주문·마지막 입장을 처리한다. 명시적 날짜 휴무는 일반 미래 시간표의 불확실성보다 우선한다. DST 중복·존재하지 않는 현지 시각은 확인 필요다. 파싱하지 못한 휴일 규칙은 명시적으로 미확인이다.

`max_party`와 `min_party`는 한 예약 인원이다. `facility_capacity`가 있어도 대체하지 않는다. 아동 나이나 식단·접근성 필수 정보가 없으면 적합으로 처리하지 않는다. 현재 잔여석·예약 완료를 추론하지 않으며 모든 카드에 잔여석 미확인을 남긴다. 실제 슬롯 조회는 이 엔진의 완료 범위가 아니다.

`usable=true`만 신뢰하지 않는다. verified 상태, 현재 정책 버전, 읽기·표시 허용, 방문일 적용, 원문 확인일, 만료를 다시 검사한다. 출처 정책이 철회되거나 자료가 만료되면 값은 반환 결과에서도 숨긴다. provisional 사실은 적합 증명이 되지 않는다.

## 설명

현재는 서버 템플릿만 사용한다. 선택된 후보와 계산된 성분에서 짧은 이유를 만든다. 선택적 설명 입력 validator는 후보 ID·순서·유형과 허용 문장·source/aggregate ID의 정확한 일치를 요구한다. 새 장소·숫자·예약 가능 표현·점수·미확인 삭제는 거부하고 같은 서버 템플릿으로 돌아간다. 외부 LLM 호출과 비용은 없다.

```sh
.venv/bin/python -m pytest tests/test_recommendation_engine.py tests/test_recommendation_api.py -q
```

```sh
.venv/bin/python -m pytest tests/test_recommendation_engine.py tests/test_recommendation_api.py tests/test_recommendation_persistence.py -q
# 57 passed, 2 warnings in 8.15s
```

순수 함수 42개, API 12개, 영구 저장 회귀 3개가 통과했다. 기존 FastAPI/Authlib의 httpx 전환 안내 경고 2개다. 합성 자료 시험이며 실제 후보의 운영·예약 가능, 언어 판별 품질, 여행 추천 품질 평가를 통과했다는 뜻이 아니다. 실제 후보팩 12곳은 출처 정책·운영자 승인 전 전부 순위에서 제외된다. 브라우저 전체 흐름 검증은 상위 작업 기록과 구분한다.
