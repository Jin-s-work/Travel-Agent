- 실패/예산 소진 때 기존 자료는 유지. 기존 업로드를 자동으로 전부 유료 재추출하지 않는다.

## 재실행과 복구

1. 일반 시험에는 `PYTHON_DOTENV_DISABLED=1`을 붙여 실제 키가 읽히지 않게 한다.
2. 실 API 시험은 위 --run 명령만 별도로 실행한다. 원문은 합성 데이터이고 격리 임시 DB에 사용량을 기록한다.
3. 운영키는 `deploy/render-supabase/.env`의 OPENAI_API_KEY에 두며 채팅/로그/Git에 복사하지 않는다. `.env.openai`는 이번 10개 설정만 담은 비공개 delta이다.
4. 설정 오류 시 free 프로필로 AI OFF, UI 문제 시 직전 이미지로 rollback. DB restore와는 별개이며 이번 변경에 DB migration은 없다.

## 운영에서 발견한 무료 → AI 전환 문제와 회귀 검증

첫 운영 재분석에서 AI 추출·임베딩은 완료됐지만 `INDEX_REBUILD_INPUT_REQUIRED`로 활성화가 거절됐다. 무료 분석으로 저장한 나머지 5개 메일에는 검색 벡터가 없었기 때문이다. 완전한 검색 세대만 활성화하는 안전 검사를 제거하지 않고, 기존 추출값에서 누락된 벡터만 예산 wrapper를 통해 준비하도록 수정했다. 기존 메일을 LLM으로 다시 추출하거나 예약·교정값을 바꾸지 않는다. 모델·청크 fingerprint·차원을 확인한 checkpoint를 재시도에서도 재사용한다.

- 초기 운영 실패 호출 비용은 이미 발생한 $0.006717로 정산 유지. 오류를 이유로 환불 처리하지 않음.
