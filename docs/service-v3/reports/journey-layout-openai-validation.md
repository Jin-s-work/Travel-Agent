# 여행 중심 레이아웃과 OpenAI 복구 — 2026-10-07

미확인 영업·인원·잔여석을 숨기거나 확정으로 바꾸지 않았다. 사진이 없으면 대체 식당 사진을 만들지 않는다. 사진 저작권 안내와 일부 부가 관리 기능의 세부 펼침은 남아 있다. 모든 부가 화면의 재설계를 완료했다는 의미는 아니다.

## OpenAI 복구

- 기존 승인된 키를 재사용. `gpt-5-mini`, `text-embedding-3-small` 실제 응답 검증.
- 합성 메일 1건에서 정확한 날짜/시각 추출, 임베딩 1536차원. 18.89초.
- 두 호출 모두 `ProviderGateway` 비용 예약·정산: 실제 사용 단가 합계 2523 micro-USD = $0.002523. 환율·세금·계정 전체 지출은 포함하지 않은 이 서비스의 API 계산값.
- 새 `pricing-openai.json`: 사용자 $0.25/일·$1/월, 전체 $0.50/일·$3/월, UTC. OpenAI 두 SKU만 허용. SDK 자동 재시도 OFF, 응답 유실은 기존 unknown 정책 유지.
- OpenAI 공식 모델 문서의 단가를 확인했다. 입력 $0.25/100만·출력 $2/100만, 임베딩 $0.02/100만. 캐시 할인은 비용 예약에 사용하지 않아 보수적으로 계산한다.
- Render/Supabase는 기존 Free 서비스. 유료 지도·리뷰·검색 키는 비움. 최소 결제·OpenAI 계정의 다른 앱 과금은 이 상한으로 제어하지 않는다.
- `scripts/prepare_render_env.py --profile openai`가 명시적 활성화 경로다. 기본 실행은 free이며 키 제거·halted 정책 유지. `--profile free`로 생성한 파일을 적용하면 유료 호출을 다시 끌 수 있다.
- 실패/예산 소진 때 기존 자료는 유지. 기존 업로드를 자동으로 전부 유료 재추출하지 않는다.

## 재실행과 복구

1. 일반 시험에는 `PYTHON_DOTENV_DISABLED=1`을 붙여 실제 키가 읽히지 않게 한다.
2. 실 API 시험은 위 --run 명령만 별도로 실행한다. 원문은 합성 데이터이고 격리 임시 DB에 사용량을 기록한다.
3. 운영키는 `deploy/render-supabase/.env`의 OPENAI_API_KEY에 두며 채팅/로그/Git에 복사하지 않는다. `.env.openai`는 이번 10개 설정만 담은 비공개 delta이다.
4. 설정 오류 시 free 프로필로 AI OFF, UI 문제 시 직전 이미지로 rollback. DB restore와는 별개이며 이번 변경에 DB migration은 없다.
