# 고잉 v5 고도화 계획

2026-10-08 · 기획 단계. 앱 수정이나 추천 성능 향상을 완료했다는 기록이 아니다.

이번 목표는 **적게 입력하고도 고를 만한 장소를 찾고, 저장한 선택을 실제 여행에 이어 쓰는 것**이다. 기존 색·Pretendard·브랜드는 유지한다.

- [PRD](PRD.md): 제품 방향, 화면 흐름, 추천·리뷰·사진 계약, 출시 기준.
- [현재 상태와 근거](AUDIT.md): 코드로 확인한 사실, 제한된 재현, 아직 확인하지 않은 부분.
- [1단계 구현 프롬프트](prompts/01-simple-discovery.md): 탐색과 선택 흐름, 상태와 실패 복구. 파일 전체를 새 구현 요청으로 사용한다.
- [2단계 구현 프롬프트](prompts/02-recommendation-quality.md): 실제 후보·리뷰·사진과 추천 평가. 1단계 기록을 확인한 뒤 파일 전체를 사용한다.
- [진행 기록](IMPLEMENTATION_STATUS.md): 이후 구현자가 실제 결과를 채운다.

1단계는 모델 교체 없이도 독립적으로 사용할 수 있어야 한다. 2단계는 실제 데이터와 품질을 확인한 기능만 도시별로 공개한다. 발표 파일·대본·README 개편은 이번 구현 범위가 아니다.

기존 service-v2~v4의 인증·소유권·예산·삭제·시간대·일정 validator 계약을 이어받는다. 특히 리뷰 검증 기준 변경은 기존 결과에 소급 적용하지 않는다. 문서와 코드가 다르면 현재 동작을 조사하고 차이를 기록한다.
