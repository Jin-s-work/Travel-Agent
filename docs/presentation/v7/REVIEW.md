# 발표·README 확인 기록

확인일: 2026-10-08. 발표 문서 검증이며 서비스 전체를 다시 시험한 기록은 아닙니다.

## 내용

- 최신 메인 추천·바로 저장·AI 질문·날짜별 답변과 출처를 실제 운영 서비스의 가상 여행으로 캡처했습니다.
- 메일·일정·마드리드 사진 화면은 이전 합성 예시이며 날짜와 범위를 별도 표기했습니다.
- 현재 `hybrid_v5` 구현과 이전 `hybrid_v4` 개발 평가를 구분했습니다. 독립 평가와 실제 만족도는 미측정입니다.
- 엄격 현지어 리뷰 추천 OFF, 무료 사진 부족, 도시별 자료 차이를 명시했습니다.
- 기존 11장 배치·남색과 밝은 배경·Pretendard를 유지했습니다. 슬라이드 3·5의 화면은 최신 캡처로 교체했습니다.

## 파일과 화면

- 최종 PPTX의 11장을 전부 렌더링해 넘침·겹침·이미지 비율을 확인했습니다.
- artifact-tool 최종 검사: 패키지 무결성, 11장 수, 16:9 크기, 제목 영역, 재가져오기 통과.
- macOS Keynote에서 새 파일을 열고 11장 대본을 확인했습니다. 변경된 3·5·9·10장은 앱 화면에서도 확인했습니다.
- 마지막 장의 내장 영상이 Keynote 슬라이드쇼에서 재생됨을 확인했습니다. MP4는 H.264, 1920×1080, 70초, 무음입니다.
- MP4는 실제 화면 캡처를 편집한 설명 영상입니다. 실시간 조작·처리 속도 측정 영상이 아닙니다.
- PPTX·Keynote에 들어간 영상과 별도 MP4의 바이트 일치를 검사합니다.
- 사용자 PDF와 이전 발표 버전은 변경하지 않았습니다.

## 다시 확인하기

```bash
python3 scripts/validate_presentation_docs.py --v7 --write-manifest
```

PowerPoint 앱, 강의실 장비, 다른 운영체제에서의 재생은 미검증입니다. 글꼴은 내장하지 않았습니다. 발표 시간 8분 30초는 목표 배분이며 실제 낭독 측정값은 아닙니다.
