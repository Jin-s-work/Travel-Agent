- 기존 PPTX를 가져와 편집했다. 10장, 16:9, Pretendard, 청록·아이보리 색상과 기존 화면 자산을 유지했다.

- 10장 전체를 렌더링하고 각 장을 원본과 비교했다. 읽힘·잘림·배치·사진·합성 표시를 확인했다.
- 최종 PPTX를 **macOS Keynote**에서 열어 `.key`로 저장했다. 10장을 각각 선택해 실제 화면과 발표자 메모를 확인했다.
- Keynote 메모 10개를 `slides-content.json`의 기본 대본과 대조했으며 10개 모두 일치했다. PPTX와 SCRIPT.md도 같은 내용으로 검사한다.

- README·발표 안내·출처의 로컬 링크와 이미지 경로, 발표 파일 ZIP 무결성을 재실행 가능한 명령으로 검사한다.
