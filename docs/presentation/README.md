## 사용 방법

Mac에서는 `.key`를 열고 **보기 → 발표자 메모 보기**를 선택합니다. 각 슬라이드에 읽을 대본과 목표 시간을 넣었습니다. 근거 링크는 메모의 ‘낭독하지 않음’ 아래에 있습니다. PowerPoint 파일에도 같은 메모가 있습니다.

글꼴은 Pretendard입니다. 현재 Mac의 Keynote에서 표지와 사진 슬라이드, 메모, 수정 가능한 텍스트를 확인했습니다. 다른 PC의 PowerPoint·웹 슬라이드 앱은 검증하지 않았으므로 발표 전에 글꼴과 배치를 확인합니다. 글꼴은 내장하지 않았습니다.

## 촬영·재현 범위

현재 앱을 macOS Chrome에서 실행해 합성 계정·가상 메일·예약으로 촬영했습니다. 실제 사용자의 메일이나 예약은 공개하지 않았습니다. 식당은 공개 출처를 검수한 실제 지점입니다. 촬영에서는 AI 유료 호출을 사용하지 않았습니다.

저장소 루트에서:

```bash
PYTHON_DOTENV_DISABLED=1 .venv/bin/python scripts/presentation_browser_fixture.py
```

`http://127.0.0.1:8766`에서 합성 사용자 A로 로그인합니다. 임시 DB에 메일 3건·수동 예약 3건을 준비하고 기본 분석 후 예시 일정을 생성합니다. 이 일정은 이동·준비 여유와 시각의 미확인을 보여주기 위한 것으로 검증 완료 일정이 아닙니다. 운영 인증·자료를 사용하는 배포 스크립트가 아닙니다.

- 패키지 무결성·슬라이드 경계·제목 크기·Pretendard 사용 검사 통과. 발견된 구조 오류 0개.
- 최종 슬라이드 10장 렌더링과 개별 시각 검토. 사진·예약 모달 캡처의 잘림을 수정.
- Keynote에서 PPTX 가져오기 후 `.key` 저장, 실제 화면과 발표자 메모 확인.
- 로컬 UI에서 로그인·예약·날짜 질문·근거·실제 장소 후보·충돌 일정 표시 확인.
- 초기 예시 fixture의 일정 목록 빈 값 판정을 수정하고 새 임시 환경에서 재실행.
- 본문에 적힌 Python 1,039 / JavaScript 124는 기존 최신 코드 검증 기록이며 이번 문서 변경의 재시험 수치가 아님.
