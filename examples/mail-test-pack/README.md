# 직접 해보는 예약 메일 테스트

모든 업체·주소·예약번호·여행자는 합성입니다. 실제 예약이 아니며 메일을 발송하거나 링크를 실행하지 않습니다. 테스트 자료에는 개인정보·비밀키가 없습니다.

## 먼저 확인할 점

무료 모드에서도 **메일에 명시된 날짜·장소·예약 항목을 기본 규칙으로 분석**할 수 있습니다. 외부 AI·임베딩 호출이나 유료 API를 사용하지 않습니다. 업로드 화면에서 현재 방식이 **기본 분석**인지 확인하세요. 예약을 추출했더라도 원문과 비교해 확인·교정해야 합니다.

기본 분석은 모든 언어와 자유로운 메일 형식을 이해하는 AI가 아닙니다. 복잡한 형식, 모호한 날짜·시각, 미확정 변경 요청은 지원하지 않거나 확인이 필요할 수 있습니다. 분석하지 못한 메일은 원문을 보존하므로 내용을 확인한 뒤 **예약 직접 추가**로 입력하세요. 재시도만 반복한다고 복잡한 형식의 인식률이 높아지지 않으며, 실패를 예약 0개 분석 성공으로 읽지 마세요.

AI 상세 분석은 서버에 키·단가·예산·외부 호출 허용이 설정된 경우에만 사용합니다. 기본 분석을 이용하기 위해 키를 추가하거나 결제를 켤 필요는 없습니다. 로컬 fake provider는 복구·화면 검증용이며 실제 언어 이해 정확도를 증명하지 않습니다.

## 준비: 테스트 여행 만들기

- `메일 연습 · 도쿄`: 2026-11-06 ~ 2026-11-09, 성인2, 도시 도쿄.
- `메일 연습 · 마드리드`: 2026-11-12 ~ 2026-11-16, 성인2, 도시 Madrid/마드리드.
- DST 사례는 별도 `시간대 연습`: 마드리드 2026-10-25 하루.
- 8건 사례는 별도 빈 도쿄 여행 2026-11-07 하루. 다른 메일을 섞으면 총9건이라는 기대값이 달라집니다.

## 업로드와 확인

1. ZIP을 풀고 해당 여행에서 **예약 → 메일로 예약 추가 → 파일 선택**으로 `.eml` 한 개를 올립니다. ZIP 자체는 메일이 아닙니다.
2. 파일별 완료/일부 완료/실패와 **내용 확인 필요** 표시를 확인합니다. 결과가 나오면 바로 아래 예약 목록에서 원문과 대조하세요.
3. 예약 목록과 `expected-results.json`의 의미를 비교합니다. JSON은 목표 의미를 설명하는 참고 자료이며, 모든 항목을 무료 기본 분석이 자동으로 채운다는 보증이나 자동 추출 결과 파일이 아닙니다. 없는 인원·가격·시각이 임의로 생성되지 않는지도 확인하세요.
4. 예약 상세에서 한 값을 교정하고 새로고침합니다. 교정값·출처가 유지되는지 확인합니다.
5. 같은 파일을 같은 여행에 다시 올리고 중복 표시를 확인합니다. 다른 여행의 같은 파일은 별도 소유 범위입니다.
6. 기본 분석이 지원하지 않는 항목은 원문과 JSON을 참고해 **예약 직접 추가**로 만드세요. **내 여행에 물어보기**에서 해당 날짜 예약을 요청하고, 새로고침 후 데이터가 유지되는지 확인합니다.

## 사례별 포인트

|파일|확인할 내용|
|---|---|
|01 왕복 항공|왕복 두 예약, 출발/도착 네 사건과 현지 시간대|
|02 도쿄 숙소|3박, 체크인/아웃 구분, 숙박을 종일 busy로 막지 않음|
|03 식당|아동 나이 미확인, 보증금과 최종 가격 분리|
|04 마드리드 숙소|Madrid가 Barcelona로 변하지 않음|
|05 복수 예약|한 메일의 두 예약을 개별 교정·삭제|
|06 날짜만 있음|정확한 시각·인원·가격은 미확인|
|same-name-a/b|같은 reservation.eml 파일명, 서로 다른 내용 보존|
|07 하루8건|빈 여행에서8건+수동1건=전체9건 조회|
|08 변경 요청|미확정 요청을 확정 예약/사용자 교정으로 덮어쓰지 않음|
|09 HTML|본문 추출, 링크 자동 실행 없음|
|10 DST|중복되는 현지시각은 UTC 확정 금지|

08 변경 요청과 10 DST 사례는 확인이 필요한 정보를 임의로 확정하지 않는지 보는 경계 시험입니다. 기본 분석이 자동 등록하지 않고 원문 확인을 요청하는 것도 올바른 안전 처리일 수 있습니다.

재분석은 저장된 메일의 **다시 분석** 기능으로 실행하세요. 08 파일을 따로 업로드했다고 자동으로 동일 예약 병합이 완료됐다고 가정하지 않습니다. 삭제 시험은 이 합성 여행에서만 하세요. 실제 외부 예약의 취소와 무관합니다.
